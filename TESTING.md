# Проверки версии 1.6.0

## Выполнено

**117 тестов — PASS, 0 ошибок.** Команда:

```sh
node --experimental-strip-types --test tests/runtime.test.mjs tests/domain.test.mjs tests/api.test.mjs tests/setup.test.mjs tests/journey-v16.test.mjs
```

Среда: Node.js 22.16.0, Linux. Проверялись доменные операции и реальный локальный HTTP API с SQLite, cookie-сессиями, ревизиями, изоляцией scope и восстановлением после перезапуска.

Новый `journey-v16.test.mjs` содержит восемь приёмочных тестов: три полных пути для HG SDLC, Maestro и AI Conductor; порядок и права платформы; four-eyes; подходящие задачи и неизменяемые версии судей; review/publish знаний; обновление политики и перевыпуск. В полном пути создаются 8 задач, две проходят Supervised, выполняется 2-кейсный benchmark, UAT, решение по риску и шесть автономных задач. Дополнительный Checks включён в сохранённый Workflow.

Строгая TypeScript-проверка доменного слоя (`lib`, кроме неизменённого `utils.ts`, которому требуются внешние библиотеки) — без ошибок. Готовая сборка пересобрана `scripts/build-offline.cjs` с TypeScript 5.8.3 и закреплённым runtime из исходного архива.

Проверка интерфейса Chromium / Playwright: нулевой экран, продукт и команда, добавление участников, выбор Maestro, переход к ресурсам, консоль Workflow, широкий диалог и запуск, мастер «задачи → судья», отчёт 2/2 PASS с двумя строками на кейс, новое знание → review → publish → граф, описание доставки и переход к предварительной проверке выпуска. Ошибок JavaScript в этом проходе не было. API использовался для подготовки части промежуточных данных и завершения гейтов; эти операции отдельно покрыты серверными тестами.

В среде проверки URL-навигация Chromium запрещена системной политикой. Поэтому собранные CSS/JS загружались в локальный DOM, а fetch направлялся через тестовый мост к настоящему серверу на localhost. Политики браузера не менялись. Это проверка исполнения интерфейса, но не обычный прогон навигации на пользовательской машине.

Копия исходного SQLite с WAL успешно прочитана после миграции: сохранены исходные 12 задач и 45 запусков сценария с данными; сценарий с нуля остался пустым. Число существующих задач намеренно не изменялось. Создание новой партии Dependency Update предлагает 8 задач.

## Не выполнялось в этой среде

Полные `npm ci`, Vite build, общий React/Vite typecheck, SSR `test:render` и dev/HMR `test:dev` не выполнены: реестр npm был недоступен, библиотечные зависимости отсутствовали. Вместо Vite собран и проверен включённый offline-dist. Команды стандартной сборки и отдельные тесты сохранены для окружения с установленными зависимостями. `npm test` выделен в независимый серверный набор, чтобы работать и с готовым архивом без npm ci.

Не проверялись и не заявляются внешние вызовы Git/Jenkins/MCP, настоящая LLM, уязвимости библиотек, реальное покрытие тестами и промышленное исполнение. Это граница симулятора, а не результаты внешних проверок.
