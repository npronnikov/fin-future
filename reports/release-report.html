Метод проверки

Настоящий Node HTTP сервер и сохраняемые данные. Browser UI выполнялся в Chromium 144.0.7559.96. Стенд блокирует навигацию на HTTP-origin; UI загружался через about:blank и HTTP bridge. Подмена предметного состояния через DevTools в центральных UI-сценариях не использовалась.

Bridge не доказывает native browser cookies, sessionStorage reload или EventSource reconnect. Нативный серверный SSE, scoped reads, session invalidation и restart проверены Node HTTP tests. Проверка окончательного ZIP публикуется отдельно после упаковки.

Среда: Linux-6.18.44-x86_64-with-glibc2.41; Node v22.16.0; npm 10.9.2.
