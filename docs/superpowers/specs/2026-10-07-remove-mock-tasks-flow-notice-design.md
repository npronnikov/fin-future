# Удаление Flow-подсказки из диалога моковых задач

## Цель

В диалоге «Добавить моковые задачи» не показывать блок «Следующий шаг — Flow» с текстом о тегах, каталоге Flow, Skills и Subagents.

## Изменение

- Удалить информационный `Notice` из формы добавления моковых задач.
- Удалить импорт `Notice` из `components/kontur/tasks.tsx`, если он больше не используется в этом файле.
- Не менять описание диалога, поля формы, доступность кнопок и обработчик добавления задач.

## Проверка

- Добавить регрессионную проверку отсутствия удалённого заголовка и текста в реализации диалога.
- Запустить соответствующий тест рендеринга, TypeScript-проверку и полный набор тестов проекта.

## Границы

Другие подсказки о Flow на странице Task Board и в остальных разделах остаются без изменений.
